# План

## Шаги

1. **Модель данных: слои** — заменить единственный глобальный `timeSignatureQueueState`
   на массив `layers`, каждый со своей очередью тактов и собственным (опциональным)
   переопределением темпа/звука/акцента. Готово = AC-1.

2. **Планировщик на несколько слоёв** — один цикл `scheduler()` обслуживает все слои
   одновременно от общего момента старта `t0`; у каждого слоя используется его
   эффективный темп/звук/акцент (переопределение слоя либо fallback на глобальные
   значения). Готово = AC-2, AC-3.

3. **UI подложек и тайлинг-раскладка** — контейнер, авторазмещающий подложки без
   свободного позиционирования; кнопка «+» рядом с подложками создаёт новую чистую
   подложку с одним тактом 4/4; у каждой подложки — кнопка удаления слоя. Готово = AC-4, AC-5.

4. **Drag-and-drop своп подложек** — перетаскивание одной подложки на другую меняет их
   местами в раскладке и в порядке данных (тайл-своп, не свободное перемещение). Готово = AC-6.

5. **Переопределение темпа/звука/акцента на уровне слоя** — на подложке переключатель
   «своё значение», при включении показывает локальные контролы, перекрывающие глобальные
   для этого слоя. Готово = AC-7, AC-8.

6. **Независимая визуализация каждого слоя** — подсветка активного такта и точек текущей
   доли работает раздельно и корректно для каждого слоя при одновременном воспроизведении,
   без утечек при удалении слоя во время игры. Готово = AC-9.

7. **Мобильная адаптация тайлинга** — на узких экранах (≤480px) подложки складываются
   в вертикальный стек без горизонтального скролла и без обрезки контента. Готово = AC-10.

## Acceptance criteria

AC-1: Дано — main.html открыт впервые (свежая загрузка, до любых действий пользователя).
      Когда — страница отрендерена.
      Тогда — в DOM ровно одна подложка (слой) с одним тактом 4/4, без переопределений —
      сохранено текущее поведение по умолчанию.

AC-2: Дано — два слоя, оба с тактом 4/4, глобальный темп 120 BPM, ни у одного темп
      не переопределён.
      Когда — нажата общая кнопка Play.
      Тогда — оба слоя стартуют первую долю в один и тот же момент `AudioContext.currentTime`
      (проверяется логированием времени `source.start()` первого клика каждого слоя —
      расхождение практически нулевое, в пределах одного тика планировщика).

AC-3: Дано — слой A: темп не переопределён (глобальный 120 BPM), такт 4/4. Слой B:
      темп переопределён на 90 BPM, такт 3/4.
      Когда — воспроизведение запущено.
      Тогда — интервал между последовательными кликами слоя A ≈ 0.5с (60/120), слоя B ≈
      0.667с (60/90) — проверяется логированием времени `source.start()` подряд идущих нот
      каждого слоя.

AC-4: Дано — приложение с одним слоем в состоянии покоя.
      Когда — нажата кнопка «+» добавления слоя.
      Тогда — появляется вторая подложка с одним тактом 4/4 без переопределений;
      обе подложки видны одновременно на экране без перекрытия друг друга.

AC-5: Дано — два и более слоёв.
      Когда — нажата кнопка удаления на одной из подложек.
      Тогда — эта подложка пропадает из DOM и её состояние — из массива `layers`;
      оставшиеся слои продолжают отображаться и (если играли) продолжают воспроизведение
      без сбоя.

AC-6: Дано — три подложки в раскладке в порядке A, B, C.
      Когда — подложка A перетащена (drag) на подложку C.
      Тогда — порядок в раскладке становится C, B, A; содержимое каждой подложки
      (такты, переопределения) остаётся привязано к ней — переставляются позиции,
      а не данные внутри.

AC-7: Дано — подложка с включённым переопределением звука на electronic при глобальном
      наборе acoustic.
      Когда — воспроизведение запущено.
      Тогда — эта подложка звучит буфером electronic/click.mp3 (и accent.mp3), остальные
      слои без переопределения — буфером глобального набора acoustic.

AC-8: Дано — подложка с включённым переопределением «акцент на первую долю» = выключено,
      при глобальном чекбоксе включённом.
      Когда — воспроизведение запущено.
      Тогда — первая доля такта в этой подложке звучит обычным (не акцентным) буфером;
      у слоёв без переопределения первая доля — акцентным.

AC-9: Дано — два слоя с разной длиной такта (4/4 и 3/4) играют одновременно ≥10 секунд.
      Когда — наблюдаем визуальную подсветку в обеих подложках в один и тот же момент.
      Тогда — активная точка-доля и подсветка такта в каждой подложке независимо
      соответствуют текущей доле именно этого слоя, без смешения с другой подложкой.

AC-10: Дано — ширина вьюпорта ≤480px, два и более слоёв.
       Когда — страница отрендерена.
       Тогда — подложки идут одна под другой (вертикальный стек), нет горизонтального
       скролла страницы, контролы каждой подложки не обрезаны.

## Non-goals
(см. `brief.md` — раздел «Скоуп»: без пресетов между сессиями, без независимого Play/Stop
по слоям, без свободного позиционирования при перетаскивании, без новых звуковых наборов.)

## Открытые вопросы — решены здесь
- **Лимит числа слоёв?** Жёсткого лимита нет — ограничено только производительностью
  браузера. Если в аудите (стадия 8) всплывёт деградация при большом числе слоёв —
  фиксируется как находка, а не блокер плана.
- **Можно ли удалить последний слой (дойти до нуля)?** Да, по аналогии с текущей логикой
  тактов: при нуле слоёв и нажатии Play создаётся один дефолтный слой (такт 4/4),
  так же как сейчас автосоздаётся такт при пустой очереди.
